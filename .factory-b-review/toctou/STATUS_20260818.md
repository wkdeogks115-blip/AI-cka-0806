## Minimal patch candidate
Candidate version: `v1.0.4-patch-candidate`

Patch design:
- open package root once with `O_DIRECTORY|O_NOFOLLOW`
- traverse parents through `dir_fd` / openat-style descriptor anchoring
- open leaf with `O_NOFOLLOW`
- read bytes from the opened file descriptor instead of re-resolving the path
- inventory opened directory tree without following symlinks
- fail closed when required POSIX secure-open primitives are unavailable
- explicitly state that atomic multi-file snapshot semantics still require a quiescent/read-only input directory
