# AI 오케스트레이션·품질예산 연구소

이 저장소는 ChatGPT 프로젝트에서 진행한 AI 오케스트레이션 연구를 장기 보존하고 다음 대화·도구·플랫폼에서 이어가기 위한 Source of Truth입니다.

업로드 상태: `INITIALIZING_FULL_HANDOFF_UPLOAD`

최종 업로드 후 다음 자료가 포함됩니다.

- Monorepo Skeleton 전체 Source
- Reference Architecture·Ownership·검증 계약
- 91A·91B·공용 답변부스터 기준본과 주요 산출물
- 120~127 연구 산출물
- 현재 상태와 다음 실행 명령
- 128 전체 인수인계 ZIP 원본

주의: 설계·Skeleton PASS는 실제 Runtime·Skill·성능 PASS가 아닙니다.
